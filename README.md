# Games_Rater_V0.1
A dynamic web application designed to evaluate, rate, and rank video games across granular gameplay categories with a custom user dashboard.
---

## 📸 Overview

The **Games_Rater_V0.1** simplifies video game evaluation by guiding users through a structured questionnaire. Instead of giving a single subjective score, users evaluate individual aspects of a game to generate an accurate overall rating.

### Key Features
- **Multi-Criteria Evaluation:** Ask tailored questions for **Art**, **Sound**, **Gameplay**, and mechanics on a scale of 1 to 10.
- **Automated Score Calculation:** Computes a balanced final rating based on category scores.
- **Visual Cover Art Support:** Allows users to attach cover images for each game entry.
- **Sorted Dashboard:** Displays all reviewed games in order of score on an intuitive grid dashboard.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Python (Flask / HTTP Server)
- **Data Storage:** JSON / File storage
